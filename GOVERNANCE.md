# Governance

Argmend has one maintainer, Sebastien Tardif.

## Decisions

Changes land on `main` through a pull request. CI and DCO are required. The maintainer approves the pull request.

A release is the Release Please pull request. Merging it tags the version and publishes the crate. Do not publish from a laptop.

## Security and conduct

Report vulnerabilities through [SECURITY.md](SECURITY.md). The code of conduct is [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). A report about a person's conduct goes to sebtardif@ncf.ca.
