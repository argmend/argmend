# Security

Report a vulnerability in private through [GitHub Security Advisories](https://github.com/argmend/argmend/security/advisories/new).

Do not open a public issue for a security report. Include the version, the input, and what an attacker can do with the result. We review a private report and reply on the advisory within 14 days. Fixes are noted in [CHANGELOG.md](CHANGELOG.md). A reporter who asks to be named is credited in that changelog.

Argmend produces JSON for a host to validate. A repair that accepts a value the schema should reject is a bug. Send that report the same way.
